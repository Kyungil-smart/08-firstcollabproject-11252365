# Stock Clicker (개미 탈출기) 기획 문서

## 1. 프로젝트 개요

### 1-1. 기본 정보

* 게임명: Stock Clicker (개미 탈출기)
* 장르: 2D 클리커 / Idle 게임
* 플랫폼: PC 우선 / 모바일 후순위
* 엔진: Unity
* Unity 버전: 6000.3.9f1
* 개발 형태: 1인 개인 프로젝트

### 1-2. 게임 소개

Stock Clicker (개미 탈출기)는 주식 투자 테마를 적용한 2D 클리커 / Idle 게임이다.
플레이어는 거래를 실행해 현금을 벌고, 업그레이드와 자동 투자 시스템을 통해 총 자산을 키워 나간다.

게임은 실제 주식 매수/매도 시뮬레이션을 깊게 재현하기보다, 클리커 장르의 핵심인 반복 성장 루프에 투자 테마를 가볍게 결합한 구조를 목표로 한다.

---

## 2. 핵심 플레이 구조

### 2-1. 핵심 루프

1. 거래 실행 버튼을 클릭한다.
2. 클릭 수익을 획득한다.
3. 현금으로 업그레이드를 구매한다.
4. 클릭 효율과 자동 수익 효율이 증가한다.
5. 자동 투자 시스템이 초당 수익을 생성한다.
6. 총 자산이 상승하고 더 높은 성장 단계에 도달한다.

### 2-2. 플레이 목표

플레이어는 거래를 통해 현금을 벌고, 자동 투자 시스템을 확장하여 총 자산을 크게 성장시키는 것을 목표로 한다.

성장은 스테이지 클리어가 아니라 **총 자산 마일스톤 기반 성장 단계**로 표현한다.

---

## 3. 자원 구조

### 3-1. 현금(Money)

현금은 실제 구매와 소비에 사용하는 핵심 재화이다.

사용처:

* 업그레이드 구매

### 3-2. 총 자산(Asset)

총 자산은 투자 지표이다.

계산식:

* `Asset = Money + 자동 투자 업그레이드 누적 비용 합`

총 자산은 직접 소비하지 않으며, 보유 현금과 자동 투자 시스템에 투입된 누적 투자 규모를 보여주는 지표로 사용한다.

### 3-3. 화폐 및 수치 처리 규칙

* 모든 재화는 달러($) 단위를 사용한다.
* 내부 계산용 자원 타입은 큰 수 증가에 대응하기 위해 `double`을 사용한다.
* 일반 표시는 정수 달러 기준으로 처리한다.
* 큰 수는 K / M / B 축약 표기를 사용하며, 가독성을 위해 소수점 한 자리까지 허용한다.

표기 예시:

* `$1,250`
* `$12.5K`
* `$3.2M`

## 4. 주요 시스템

### 4-1. 클릭 시스템

* 화면 중앙에 대형 **거래 실행 버튼**을 배치한다.
* 버튼을 클릭하면 현재 클릭 수익만큼 현금을 획득한다.
* 버튼 그래픽은 차트 또는 증권 앱 UI를 연상시키는 스타일로 구성한다.
* 클릭 시 수익 증가를 직관적으로 보여주는 숫자 팝업을 출력한다.

### 4-2. 수동 거래 강화 업그레이드

수동 거래 강화 업그레이드는 아래 3종으로 구성한다.

#### 거래 감각 향상

* 구매 1회당 클릭 파워 +1

#### 클릭 보정 모듈

* 구매 1회당 클릭 수익 배율 +10%

#### 집중 매매

* 구매 1회당 클릭 수익 배율 +15%

### 4-3. 클릭 수익 계산식

* `기본 클릭 파워 = 1 + 거래 감각 향상 구매 수 × 1`
* `최종 클릭 수익 = 기본 클릭 파워 × (1 + 클릭 보정 모듈 구매 수 × 0.10 + 집중 매매 구매 수 × 0.15) × 시장 상태 배율`
* 클릭 수익은 내부적으로 double로 계산하고, 표시는 화폐 표기 규칙을 따른다.

### 4-4. 자동 투자 시스템

자동 투자 시스템은 초당 수익을 발생시키는 구조로 설계한다.

자동 투자 업그레이드는 아래 3종으로 구성한다.

#### 개미 봇

* 구매 1회당 초당 수익 +1

#### 수익 스캐너

* 구매 1회당 자동 수익 효율 +20%

#### 알파 엔진

* 구매 1회당 자동 수익 추가 배율 +10%

### 4-5. 자동 수익 계산식

* `기본 자동 수익 = 개미 봇 구매 수 × 1`
* `최종 자동 수익 = 기본 자동 수익 × (1 + 수익 스캐너 구매 수 × 0.20) × (1 + 알파 엔진 구매 수 × 0.10) × 시장 상태 배율`
* 자동 수익은 내부적으로 double로 계산하고, 표시는 화폐 표기 규칙을 따른다.

### 4-6. 업그레이드 비용 공식

모든 업그레이드 비용은 아래 공식을 따른다.

* `다음 비용 = 기본 비용 × 1.15^구매 횟수`

비용 계산 시 소수점이 발생하면 올림 처리한다.

### 4-7. 업그레이드 데이터 관리

* 업그레이드 이름, 기본 비용, 효과량, 비용 증가 배율은 코드가 아닌 데이터로 분리 관리한다.
* 1차 구현에서는 ScriptableObject 기반 관리 구조를 사용한다.
* 업그레이드 구매 횟수는 런타임 상태이자 저장 데이터로 관리하며, 원본 데이터와 분리한다.

## 5. 시장 상태 시스템

### 5-1. 시장 상태 종류

시장 상태는 아래 3단계로 구성한다.

* 약세장
* 보합장
* 강세장

### 5-2. 시장 상태 배율

* 약세장: `0.85`
* 보합장: `1.00`
* 강세장: `1.15`

### 5-3. 시장 상태 규칙

* 시장 상태는 20초마다 변경 판정을 수행한다.
* 변경 시 약세장, 보합장, 강세장 중 하나를 랜덤 선택한다.
* 동일한 시장 상태는 최대 2회까지만 연속 등장할 수 있다.
* 동일 상태가 2회 연속 등장한 경우, 다음 변경에서는 해당 상태를 후보에서 제외한다.
* 게임 시작 시 시장 상태는 보합장으로 시작한다.
* 시장 상태 변경 타이머는 게임 시작 즉시 동작한다.

### 5-4. 시장 상태 적용 대상

시장 상태 배율은 아래 두 요소에 모두 적용한다.

* 클릭 수익
* 자동 수익

---

## 6. 성장 단계

### 6-1. 성장 단계 기준

성장 단계는 총 자산(Asset) 기준으로 상승한다.

### 6-2. 성장 단계 구성

* 1단계: 초보 개미
* 2단계: 성장 개미
* 3단계: 큰손 개미
* 4단계: 세력 개미
* 5단계: 시장 지배자

### 6-3. 성장 단계 마일스톤

* 1단계: `0 ~ 9,999 Asset`
* 2단계: `10,000 ~ 99,999 Asset`
* 3단계: `100,000 ~ 999,999 Asset`
* 4단계: `1,000,000 ~ 9,999,999 Asset`
* 5단계: `10,000,000 Asset 이상`

## 7. UI 구성

### 7-1. 상단 HUD

상단 HUD에는 아래 정보를 표시한다.

* Money
* Asset
* 시장 상태
* 클릭 파워
* 초당 수익

### 7-2. 중앙 영역

* 화면 중앙에 거래 실행 버튼을 배치한다.

### 7-3. 우측 패널

* 화면 우측 패널에 업그레이드 리스트를 배치한다.

표시 항목:

* 업그레이드 이름
* 업그레이드 설명
* 현재 구매 수
* 다음 구매 비용

### 7-4. 보조 UI

* 클릭 팝업
* 옵션 버튼
* 세이브 초기화 버튼(확인 팝업 포함)

## 8. 세이브 / 로드 규칙

### 8-1. 저장 규칙

* 게임 시작 시 자동 로드한다.
* 업그레이드 구매 시 자동 저장한다.
* 1분마다 자동 저장한다.
* 게임 종료 시 자동 저장한다.

### 8-2. 저장 대상

* Money
* 수동 거래 강화 업그레이드 구매 수
* 자동 투자 업그레이드 구매 수
* BGM 볼륨 설정값
* SFX 볼륨 설정값

### 8-3. 비저장 대상

* 현재 시장 상태
* 시장 상태 변경 타이머 진행도
* 동일 상태 연속 등장 횟수

### 8-4. 로드 규칙

* 저장 데이터 로드 후 Asset은 현재 Money와 자동 투자 업그레이드 구매 수, 업그레이드 비용 공식을 기준으로 다시 계산한다.
* 저장 데이터 로드 후 클릭 수익, 자동 수익, 현재 성장 단계는 현재 원본 데이터와 복원된 상태를 기준으로 다시 계산한다.
* 게임 시작 시 시장 상태는 보합장으로 초기화한다.
* 시장 상태 변경 타이머와 동일 상태 연속 등장 횟수는 초기화한다.

## 10. 완성 기준

1. 거래 실행 버튼 클릭 시 Money가 정상적으로 증가한다.
2. 거래 감각 향상, 클릭 보정 모듈, 집중 매매가 클릭 수익 계산에 정상 반영된다.
3. 개미 봇, 수익 스캐너, 알파 엔진이 자동 수익 계산에 정상 반영된다.
4. 시장 상태가 약세장 / 보합장 / 강세장으로 정상 전환된다.
5. 시장 상태 배율이 클릭 수익과 자동 수익에 정상 반영된다.
6. Money, Asset, 시장 상태, 클릭 파워, 초당 수익이 UI에 정상 표시된다.
7. 업그레이드 구매 시 비용 증가 공식이 정상 적용된다.
8. 세이브 후 재실행 시 자원과 업그레이드 상태가 유지된다.
9. Asset이 Money와 자동 투자 업그레이드 누적 비용 합 기준으로 정상 계산된다.
10. 플레이어가 클릭 → 업그레이드 → 자동 투자 시스템 확장 → 성장 단계 상승의 루프를 반복적으로 체험할 수 있다.

---

## 11. 정리

Stock Clicker (개미 탈출기)는 거래 실행을 통해 현금을 벌고, 업그레이드와 자동 투자 시스템을 통해 총 자산을 키워 나가는 2D 클리커 / Idle 게임이다.

게임은 반복 성장 루프를 중심으로 구성되며, 시장 상태 변화와 투자 테마를 가볍게 결합해 직관적인 성장감과 장기 목표 달성 경험을 제공한다.
